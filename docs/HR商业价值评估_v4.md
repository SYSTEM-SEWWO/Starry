## 一、一句话定位

**「一个长在桌面上的免费 AI 工作台」**——翠绿与白的设计语言、液态玻璃质感的小悬浮球，背后是 17 家云服务商 + 本地模型的自由切换、可扩展的智能体（技能 + 工具 + 插件市场），以及 v4 新增的三大生产力能力：**资料库（知识检索）、自动化（定时任务）、专家会诊（多智能体协作）**。

## 三、与 WorkBuddy 的正面对标（本轮核心问题）

WorkBuddy（腾讯全场景 AI 工作台）的核心能力图谱与本产品 v4 的对应关系：

| WorkBuddy 能力 | 本产品 v4 对应实现 | 对标结论 |
|---|---|---|
| 自然语言交互 + 自主规划执行 | 智能体框架（OpenAI tools 协议 + 多轮循环） | **对等**（协议开放，模型不限） |
| 多模态任务（文档/表格/PPT） | 文件 / 图片 / 截图提问，Markdown 富文本渲染，对话导出 Markdown | **部分对等**（缺表格/PPT 产物生成，见 P1-1） |
| 本地文件操作 | 文件读取工具 + 资料库导入 | **对等** |
| **资料库（知识检索）** | 本地文档导入 + 段落分块 + TF-IDF 检索 + 对话自动注入 + `search_library` 工具 | **对等**（本地优先，隐私更优） |
| **自动化工作流** | 定时 / 间隔任务，到点后台执行，结果写入专属会话 + 托盘提醒，关闭期间错过自动补行 | **对等（本地简化版）** |
| **多专家并行协作** | 专家会诊：N 位技能专家并行回答，主持人 AI 综合输出，实时进度 | **对等（简化版）** |
| 插件市场 / 连接器 | 三级插件市场（工具包 / 技能包 / 代码插件）+ 远程索引 | **对等**（代码插件是双刃剑，见风险） |
| 多任务并行 | 多会话 + 会诊并行请求 | **部分对等** |
| 云端账号体系 / OPC 一人公司 | ✗ | **缺失**（涉及商业模式，见 P0-2） |

**结论**：v4 完成了对 WorkBuddy **「生产力三角」（资料库 × 自动化 × 多智能体）** 的复刻，且以「零服务器成本、数据全本地、模型不绑定」形成差异化。产品叙事可以从「AI 聊天工具」升级为**「本地优先的 AI 工作台」**——这是一个更大的市场故事。

## 四、用户价值与 ROI（v4 增量）

| 用户获得 | 量化估计 |
|---|---|
| **资料库** | 把散落的文档/笔记/代码变成「可对话的知识」；相比每次手动复制文档给 AI，单次节省 3-5 步操作；私有文档不出本机 |
| **自动化** | 「早间简报」「周报素材」类重复性提示词从每天手动发送变为零操作；按每周省 30 分钟计，年省 ≈ 26 小时 |
| **专家会诊** | 重要决策前获得多视角交叉验证；相比逐个询问，一次会诊 = 1 次操作换取 3-4 个独立视角 + 1 个综合结论 |
| 设计语言统一 | 第一眼 Professional 感；翠绿 + 白在国产效率工具中建立视觉记忆点 |
| 零订阅费 | 相比 $20/月订阅，年省 ≈ $240（v3 结论延续） |

## 五、商业模式（在 v3 分层基础上的修订）

1. **个人免费版（当前）**：完整功能，BYO Key。目标：规模与口碑。
2. **云端托管版**：官方代管免费模型额度。**v4 判断不变**：这仍是最大转化断点（没有 API Key 的用户占大多数），建议 v5 单独立项预研。
3. **团队版**：共享技能/提示词库、资料库团队版（当前资料库为单机）、用量看板。按席位收费。
4. **插件市场抽成**：代码插件付费安装，平台抽 15-30%。
5. **企业私有化**：本地模型 + 内网部署 + 资料库（数据不出内网是刚需），卖 License + 维保。

> 关键洞察更新：**v4 之后，「资料库」成为最强的企业私有化卖点**——它同时命中「数据主权」与「知识复用」两个企业采购动机；而「自动化」是个人用户留存引擎（任务跑起来就舍不得走）。

## 六、团队与招聘视角

- **技术栈叙事升级**：Python + PyQt5 桌面端 + 智能体框架 + 本地检索（TF-IDF）+ 并行任务编排——这个组合在招聘市场是**稀缺的「全栈桌面 AI」画像**，对候选人有技术吸引力。
- 模块化进一步加深（core 纯逻辑 / app 控制器 / ui 视图三层清晰），新人 onboarding 成本继续下降。
- 建议补充角色排序调整为：**增长运营**（插件市场与资料库模板冷启动）> **UI/动效设计师**（设计语言已统一，需持续产出主题与模板）> **后端工程师**（为云端版做预研）。

## 七、风险清单（v4 更新）

| 风险 | 等级 | 说明 |
|---|---|---|
| 官方客户端 + WorkBuddy 功能挤压 | 高 | 豆包/WorkBuddy 一旦把资料库/自动化做成标配，差异化收窄；需靠「本地优先 + 模型自由」守住差异 |
| 代码插件安全 | 高 | 维持 v3 判断；v4 插件市场新增了资料库工具包（只读检索，风险低），未扩大攻击面 |

| PyQt5 生态老化 | 中 | 不变 |

## 八、HR 的修改意见（v4 轮，按优先级排序）

> 以下 7 条为要求下一轮迭代落地的具体修改。

### P0 — 必须做

1. **缺少「产物交付」闭环**：WorkBuddy 的终点是**交付物**（文档/表格/PPT），本产品对话结果只能复制或导出 Markdown。**要求**：新增「生成文档」能力——把当前会话一键转为排版良好的 Word/PDF（报表、纪要、方案三类模板），这是「聊天」与「工作台」的最后一块拼图。
2. **无云端账号与多端同步**：资料库、会话、提示词全部锁在单机。**要求**：v5 立项「账号体系 + 配置/会话云同步」预研（不挤占 v4.x 体验打磨），HR 侧同步评估合规（数据出境、密钥托管）。

### P1 — 应该做

3. **资料库检索质量可升级**：当前 TF-IDF 对同义词/改写无能。**要求**：提供「检索质量」设置项——基础（TF-IDF，默认）/ 增强（可选本地嵌入模型或云端 Embedding API），并在资料库对话框显示当前模式。
4. **自动化结果无主动消费路径**：任务结果写入「⚙ 自动化」会话后，用户不会主动去看。**要求**：会到点时若窗口不可见，用托盘气泡通知 + 点击直达该会话；关于对话框增加「最近自动化结果」入口。
5. **会诊成本无感知**：一次会诊 = N+1 次 API 调用，免费额度用户可能一次烧完当日配额。**要求**：开始会诊前显示预估调用次数与当前服务商配额提示；支持「仅看专家回答、跳过主持人汇总」以省一次调用。

### P2 — 建议做

6. **设计语言资产化**：翠绿色板已令牌化，但未对外。**要求**：产出一页「设计规范」文档（色板 / 圆角 / 动效时长 / 组件状态），作为开源项目的 `DESIGN.md`——既是协作基础，也是技术品牌资产。
7. **空场景引导覆盖新功能**：资料库为空、无自动化任务、未会诊过时，界面均无引导。**要求**：三个新功能各自的空状态给出「一键开始」动作（导入第一个文档 / 创建第一个任务 / 发起第一次会诊）。

## 九、结语

v4 是一次**「三个视角的一次性交付」**：美术给了它统一的脸（翠绿 + 白），工程师给了它清晰的骨（三层架构 + 控制器拆分），创新者给了它 WorkBuddy 的生产力三角（资料库 × 自动化 × 会诊）。产品完成度从 v3 的 B+ 提升至 **A-**：**体验 A，架构 A-，商业完整度 B+（差在产物交付与账号体系两块 P0）**。

下一轮的关键已经清晰：**把「对话」变成「交付」，把「单机」变成「可同步」**。这两块补上，产品就具备了从「开源精品」走向「可运营商品」的全部要件。

**综合评级：A-（体验 A，架构 A-，商业完整度 B+，安全 A-）**
