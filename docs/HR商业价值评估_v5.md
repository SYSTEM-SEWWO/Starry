## 三、本地模型战略评审（本轮核心问题）

v5 最重的商业决策是「自带模型市场」。HR 视角逐条审视：

### 3.1 为什么这是对的方向

| 维度 | 结论 |
|---|---|
| 获客 | 「免费 + 本地 + 中文模型一键下载」对价格敏感用户与隐私敏感用户（法务、财务、政务）是杀手组合，下载即用没有 Ollama 的环境配置门槛 |
| 留存 | 模型库是一个**可增长的本地资产**：用户下载的 GGUF 沉没成本越高，迁移离开的概率越低 |
| 成本 | 零服务器成本：魔塔 CDN 承担分发，llama.cpp 承担推理，产品方不付一分钱 |
| 叙事 | 「数据不出本机」是企业采购答辩时的标准加分项 |

### 3.2 HR 的担忧（必须记录在案）

- **P0-1 分发断链**：产品现在只有「源码」。Windows 用户看到 `pip install pyttsx3`、`git clone`、`python main.py` 三连就流失了。**没有 `.exe` / `.dmg` 安装包，前面所有功能对 90% 的普通用户不存在。** 这是 v5 最大的商业漏洞——不是功能问题，是**交付形态问题**。
- **P1-1 语音引擎黑盒**：TTS 依赖 pyttsx3 → espeak（Linux）/ SAPI5（Windows）/ NSSS（macOS）。产品内的降级提示只有一句话，用户照做后仍可能失败（Linux 还需 `apt install espeak`）。**「可选依赖」没有配套安装指引等于没做。**
- **P1-2 命令面板不可发现**：Ctrl+K 是高效用户的爱，但鼠标用户永远不知道它存在。标题栏没有入口，托盘虽然有菜单项但藏得深。**好功能没有入口 = 没有功能。**
- **P2-1 分卷模型下载盲盒**：7B/14B 推荐模型是双分卷（`-00001-of-00002`），下载前只显示单卷体积，用户看不到**总体积与分片数**，下载到一半发现磁盘满了会很愤怒。
- **P2-2 主题切换路径深**：四主题只能进设置 → 外观 → 下拉切换。命令面板里有「切换主题」，但同上，鼠标用户不可发现。

## 五、用户价值与 ROI（v5 增量）

以「重度个人用户（日均 30 轮对话）」估算：

- **参数精细化**：按模型存参数后，切换模型不再丢配置，每轮节省 2–3 次点击与一次心理切换，**周省约 20 分钟**；
- **本地模型**：一次配置后永久免费，若替代原 30 元/月的 API 支出，**年省 360 元**，且隐私合规；
- **命令面板**：常用功能打开时间从 5–8 秒降到 1 秒内，**日均省 3–5 分钟**；
- **对话分支**：不满意直接重新生成并保留旧答案对比，避免「生成即覆灭」的挫败，这是**留存型体验**。

## 六、商业模式评估

当前仍是「零收入纯公益」形态。v5 之后商业化的**最短路径**不变，但多了一个新选项：

1. **本地优先版（免费开源）**：保持现状，做 GitHub star 与口碑；
2. **打包发行版（9.9–19.9 元一次性）**：解决 P0-1 后即可上线，Win/macOS 安装包 + 自动更新；
3. **企业内购（按席位）**：资料库 + 本地模型 + 数据不出内网三件套已是完整的企业采购故事，缺的只是**部署文档与许可证策略**。

HR 建议：**P0-1 修复后立即做选项 2 的试卖**，这是验证付费意愿成本最低的动作。

## 七、团队与招聘视角

- 57 模块 / 14.8K 行 / 369 自测的代码库，配 21 节自测文档与三层架构图，**新人 onboarding 文档已足够支撑「一周上手」**；
- v5 新增的 `core/modelscope.py`（续传/CDN 非标准行为处理）与 `core/context.py`（上下文估算）是很好的**面试题素材**——能讲清「为什么 Range 请求返回 200 还要按 Content-Range 判定续传」的候选人，网络编程基础过关；
- 建议下一个里程碑引入一名**测试工程师**把 369 项自测升级为 CI（GitHub Actions），目前全部依赖本地手动执行，存在「最后一次提交没跑全量」的风险。

## 九、结论与行动项

**总评：v5 是「功能领先、形态落后」的一版。** 功能面已全面追平并局部领先 Cherry Studio / WorkBuddy 桌面端；但**没有安装包**让所有功能对普通用户不可见，这是 v6 前必须解决的事。

| 优先级 | 行动项 | 责任视角 | 验收标准 |
|---|---|---|---|
| **P0-1** | 提供 Win/macOS 一键打包脚本 + 首次运行指引（README 安装章节） | 资深程序员 | 全新 Windows 虚拟机按 README 三步内跑起来 |
| **P1-1** | TTS 分平台安装指引（Win 免装 / macOS 免装 / Linux 需 espeak）写入 README 与设置页 | 资深程序员 | 无引擎时产品内提示可照做成功 |
| **P1-2** | 命令面板增加标题栏 ✨ 按钮入口（鼠标可达） | 美术 + 程序员 | 不按 Ctrl+K 也能打开面板 |
| **P2-1** | 模型卡片展示分卷总体积与分片数 | 美术 + 程序员 | 7B 模型下载前可见「×2 分片 · 共 7.6GB」 |
| **P2-2** | 「切换主题」进托盘菜单 | 程序员 | 右键托盘可直接循环四主题 |
