# HR 复审 · v11.3.0

> 维度：用户价值、上手成本、留存与口碑。

## 1. 电脑端新增功能（用户价值）

| 功能 | 用户痛点 | v11.3 解法 |
|------|----------|------------|
| 消息收藏 | 长对话里有用的回答容易被刷走 | 「收藏最后回复」一键收藏；「收藏夹」跨会话聚合、双击跳转 |
| AI 总结 | 会话太长，回头找不到重点 | 「AI 总结当前会话」流式生成要点并缓存，下次直接看摘要 |
| 批量导出 | 想备份 / 迁移全部历史 | 「批量导出全部会话」支持 Markdown / JSON / TXT / HTML / ZIP |

四个入口**全部进入命令面板（Ctrl+K）**，延续「一键可达」心智，老用户零学习成本。

## 2. 安卓闪退根治（口碑 / 自助）

- 过去：安装即黑屏闪退，用户面对黑盒，只能差评或卸载。
- 现在：异常在屏上显示原因 + 提示 `logcat` 抓取，用户可自助排查、给开发者反馈，**崩溃不再是黑盒**。

## 3. 上手与迁移

- 使用指南（`使用指南_Android_APK.md` 等）随版本更新，覆盖「下载 → 安装 → 首次授权 → 核心功能」。
- 会话 / 收藏 / 摘要数据随 `sessions.json` 本地落盘，重装不丢（导出可再备份）。

## 4. 风险与建议

- 收藏以消息下标为准，编辑 / 删除前文会改变下标——已在 UI 文案与文档中说明，后续可升级为「消息 id 锚定」体验更稳。
- 演示密钥留在仓库，对外发版前建议替换为正式密钥并在文档标注。

**结论**：v11.3.0 显著提升移动端可用性与桌面端知识沉淀能力，用户价值正向，建议发版。
