# HR 复审 · v11.4.0

> 视角：用户价值 / 上手成本 / 可理解性。评审对象：消息引用（Quote）/ 分支对话（Branch）。

## 1. 用户价值
- **引用**解决高频诉求：「针对上文某句话追问」。以往用户只能复制粘贴原文或反复描述上下文，现在一键选消息即可带上引用块，回答更聚焦、更省字。
- **分支**解决另一类高频诉求：「想换个方向重试，但不想覆盖原对话」。对标 ChatGPT / Claude 网页端「从此处新建分支」，是对话类产品的核心体验补齐。
- 二者结合，让长对话具备了「局部追问 + 版本分叉」的知识管理能力，配合 v11.3 的收藏 / 总结 / 批量导出，桌面端已形成完整的会话知识闭环。

## 2. 上手成本
- 四条命令（💬 引用消息追问 / ↩️ 引用最后回复 / 🌿 分支对话 / 🌱 分支列表）**全部进命令面板 Ctrl+K**，延续「一键可达」心智，老用户零学习成本。
- 「引用最后回复」是零选择成本的快捷入口；「引用消息追问」才需要选消息 + 输入问题，按复杂度分层，符合渐进式设计。
- 消息选择器列出 `#下标 · 角色 · 摘要`，双击即选，文案直白；分支列表为空时弹出引导文案，不会让用户面对空白页困惑。

## 3. 数据安全与升级体验
- 旧 `sessions.json` **无需迁移**：新增字段缺省读取，历史数据零损升级，不打断既有用户的会话资产。
- 分支保持原会话不变，用户「试错」无心理负担，鼓励探索多方向回答。

## 4. 文档与可支持性
- `API开放文档_v11_4.md` 给出可直接运行的代码示例与接口表；`RELEASE_NOTES_v11_4.md` 给出升级方式与命令入口；客服/支持可据此快速答疑。
- 命令面板自带说明列（"选一条历史消息作为引用，针对它提问"），无需额外培训材料。

**结论**：v11.4.0 补齐了对话产品的两项关键体验，入口一致、上手成本低、升级无损，用户价值正向，建议发版。
