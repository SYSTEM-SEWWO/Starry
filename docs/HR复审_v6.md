## 二、复审特别确认的三件事

1. **一键安装不是「假按钮」**：`_KernelInstallWorker` 真实起子进程执行 `playwright install chromium`，输出逐行回调；已就绪分支有明确反馈。新用户走查路径上不再出现「回终端」动作。
2. **文案不再自我拆台**：除 P1-2 卡片外，设置页网页接入状态行对「安装包版本 vs 源码版本」的差异也做了说明（P2-1 的延伸），与 README 口径一致。
3. **坦白清单接受**：程序员主动列出 5 条已知边界（站点改版依赖/安装包不含内核/venv 环境/未真机跨平台构建/串行检查），其中第 4 条与商业化无关（CI 议题），第 1/2/3 条均已有产品内逃生舱或明示，**不影响 GA**。
