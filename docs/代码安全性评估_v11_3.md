# 代码安全性评估 · v11.3.0

> 评审范围：v11.3.0 安卓闪退根治补丁 + 电脑端新增功能（消息收藏 / AI 总结 / 批量导出）。

## 1. 安卓错误处理（新增 `_show_fatal_error`）

- 仅将**本地异常文本**拼接进 `toga.Label` 显示，全程**无 `eval` / 命令执行 / 路径拼接**，不存在注入面。
- 异常消息来自 `sys.exc_info()` 与代码内常量，非用户可控输入；不存在 XSS / 命令注入风险。

## 2. AI 总结（新增 `build_summary_prompt` / `set_summary` / `get_summary`）

- `build_summary_prompt` 为**纯函数**，仅读取消息内容拼接提示词，**不执行、不落盘外部输入**。
- 模型返回文本经 `set_summary` 存入 `session["summary"]`（截断 8000 字），下游仅做文本渲染，**无代码执行风险**。
- 过滤 `role == "system"` 与空内容，避免系统提示泄露到用户可见摘要。

## 3. 批量导出（新增 `export_all_sessions(fmt="zip")`）

- 使用标准库 `zipfile` **内存打包**，文件名由会话 `id[:8]` 生成（非用户可控串），**无 Zip Slip / 路径穿越**（只写内存缓冲，不读取外部路径）。
- `html` 格式经 `escape` 转义（`< > &`）后再拼接，导出内容不引入外部脚本。

## 4. 密钥与签名

- 演示用签名密钥 `android/starry-release.keystore` 留在仓库内，便于 CI / 本地构建；生产环境建议移出仓库、走 CI Secret。
- 已关注 `.gitignore`；建议在忽略规则中补充 `android/*.keystore` 以避免误提交（当前为演示便利保留）。

## 5. 依赖

- 新增逻辑**零新增第三方依赖**；`core` 层不引入任何联网 / 执行类包，安卓与桌面同源复用。

**结论**：v11.3.0 新增代码面无新增安全风险，可发版。
