## 2. 逐项说明与修复

### S1 · EULA 同意可被篡改绕过（High → 已修）
- **现象**：首启许可门只判断 `cfg.data.get("accepted_eula")` 是否为真。
  攻击者（或好奇用户）可直接编辑 `~/.config/.../config.json` 写入
  `"accepted_eula": true` 跳过许可，使「企业商用须同意 EULA」形同虚设。
- **修复**：引入**防篡改令牌** `eula_accept_token`——把许可正文与
  `APP_VERSION` 一起做 SHA-256（`eula_dialog.py:18-30`）。接受时同时写入
  令牌（`eula_dialog.py:_on_accept`）；`main.py:24-35` 门禁改为
  `accepted_eula AND token == eula_accept_token()`。只改布尔位、不写正确
  令牌 → 重新弹门。
- **诚实声明**：这是「防诚实篡改/绕过门槛」，非防逆向硬墙（客户端软件固有）。
  生产级管控应叠加**服务端签发 + 在线激活**（见 §4 残余风险）。

### S2 · 许可密钥明文无校验（Medium → 已修）
- **现象**：关于页直接展示 `license_key`，不校验格式/真伪，用户填任意串即
  显示「正版」。商业授权失去意义。
- **修复**：`core/config.py` 新增离线确定性校验
  （`validate_license_key` / `generate_license_key` / `is_license_valid`）：
  密钥格式 `XXXX-XXXX-XXXX-XXXX`，末 4 位为
  `sha256(固定盐 + 前 12 位)[:4]` 校验位；随机串因末 4 位不匹配被拒。
  关于页授权卡改为**可编辑 + 即时校验**（`about_dialog.py:_license_card`），
  状态显示「未填写·试用版 / ✅已验证正版 / 格式无效」。

### S3 · 配置文件无权限限制（Medium → 已修）
- **现象**：`save()` 以默认 umask 写 `config.json`，含 API Key 与许可密钥，
  多用户/共享机器上其他账号可读。
- **修复**：落盘后于 posix 平台 `os.chmod(path, 0o600)`
  （`config.py:save`）。Windows 跳过（ACL 模型不同）。

### S4 · MCP 启动命令未校验（Low → 已加固）
- **现象**：原 `subprocess.Popen([command]+args)` 失败仅抛泛型异常，用户
  难定位「命令不存在」。
- **修复 + 澄清**：启动前用 `shutil.which / os.access` 校验命令可解析
  （`mcp.py:start`），失败早返回清晰错误。
  **重要**：调用始终为**列表式、无 `shell=True`**，因此**不存在 shell 命令
  注入面**——这是安全设计的正向结论，不是隐患。

### S5 / S6（接受，标注）
- 全屏截图（看屏幕问答）由用户**主动触发**且 EULA/关于页已告知「内容仅留本机」，
  属知情同意下的预期能力，接受。
- 网页接入仅由用户配置的站点驱动、不响应远程不可信输入，SSRF 风险在可控边界，
  接受并在文档标注。

## 3. 验证

- 自测第 22 节（v7.5 新增 7 项）：令牌防篡改、密钥校验、配置 0o600、MCP 命令
  校验、危险工具护栏——**全绿**。
- 全量自测 **666 通过 / 0 失败**；`pyflakes` 对改动文件 exit=0。
- 动态验证：直编 `accepted_eula=true` 且无令牌 → 主程序仍判定未同意；
  随机 16 位串 → `validate_license_key` 返回 False；`/no/such/binary` →
  `McpClient.start()` 返回 `(False, "…不存在或不可执行…")` 且 `proc is None`。

## 4. 残余风险与下轮建议

1. **在线激活缺失**：当前为「客户端防滥用门槛」。建议 v7.6 增加服务端
   签发 + 在线激活 + 吊销，杜绝离线伪造密钥规模化。
2. **EULA 令牌可逆推**：`EULA_TEXT` 与版本号均随包发布，逆向者可重算令牌。
   建议结合设备指纹 + 服务端记录，提升绕过成本。
3. **MCP 来源可信**：`trusted` 勾选自担风险，建议在文档显著位置二次警示，
   并对 `npx`/网络拉取的服务器增加来源提示。
