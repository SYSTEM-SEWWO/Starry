- `.gitignore` 已忽略 `config.json` / `*.log` / `sessions.json` / `gateway_stats.json` / `.starry/` / `browser/`（[.gitignore](.gitignore)）。

- `git ls-files` 确认无 `config.json` 被跟踪；`git status` 中无密钥文件待提交。

### 2.2 构建产物不入库 — ✅ 通过
- `.gitignore` 忽略 `dist/` / `build/` / `星语Starry` / `星语Starry.exe` / `*.spec.bak` → 打包二进制与临时目录不会污染仓库。

### 2.3 打包隐藏导入完整性 — ✅ 通过（构建实证）
- `starrystar.spec::_HIDDEN` 已显式声明 `core.mcp` / `core.screen` / `ui.frost` / `ui.eula_dialog` 等全部懒加载模块。
- 实证：PyInstaller 构建**全程无 `ModuleNotFoundError`**，单文件 `EXE` 装配成功 → 入口 `main.py`、全部 `hiddenimports`、PyQt5 收集均正确。

### 2.4 API 开放文档不泄露密钥 — ✅ 通过
- [`docs/API开放文档_v7_6.md`](API开放文档_v7_6.md) 示例中 API Key 仅以占位 `sk-...` 出现；`KeyPool.add_key("deepseek", "sk-...")` 为示意。
