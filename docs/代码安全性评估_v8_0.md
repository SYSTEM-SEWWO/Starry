## 2. 本轮新增评估（记忆 / 推理）

### 2.1 记忆提示注入护栏 — ✅ 通过（核心安全项 S6）

长期记忆会被**拼进系统提示**（`app/assistant.py:921` `build_memory_block()`）。若记忆可被注入恶意指令，将间接操纵模型行为。本版在写入前做三重清洗（`core/memory.py::is_safe_entry`，55 行）：

- **长度上限**：单条 > 240 字符直接拒绝（`MAX_ENTRY_LEN`）。
- **HTML 标签拒绝**：含 `<` `>` `&` 的条目拒绝（`_TAG_RE`），杜绝 `<script>` / `<img onerror>` 类脚本注入（自测：`[FAIL] HTML 标签被拒` → 已 PASS）。
- **指令诱导拒绝**：正则命中 `ignore previous instructions` / `忽略之前的指令` 等模式的条目拒绝（`_INJECTION_RE`），杜绝「忽略之前指令」类提示注入（自测已覆盖中英两种）。
- **去重 / 容量上限**：`add()` 同文本只更新权重；总量 `MAX_ENTRIES=300` 超阈值按命中率淘汰，避免无限膨胀。

> 记忆**仅作纯文本注入**，从不 `eval` / 执行；思维过程（`reasoning`）同理只渲染不执行。

### 2.2 记忆落盘权限 0o600 — ✅ 通过

`MemoryStore.save()`（`core/memory.py:114`）写出 `memory.json` 后 `os.chmod(self.path, 0o600)`（仅 posix）；自测断言 `memory.json 权限 0600` 通过。该文件含用户画像，与 `config.json` 同级保护。

### 2.3 记忆「学习」来源收敛 — ✅ 通过

`learn_from_conversation()`（`core/memory.py:216`）**只从用户发言**抽取，且只匹配白名单句式（`我是 X` / `我喜欢 X` / `项目用 X`）；不学习助手输出，避免「自我暗示 / 循环污染」。禁用开关后 `learn` 直接返回 0（自测 `禁用后不学习` 通过）。

### 2.4 推理引擎无执行面 — ✅ 通过

`core/reasoning.py` 的 `split_think_content` / `StreamingThinkSplitter` 仅做字符串解析与分片，**不执行、不渲染为 HTML**（思考文本经既有 `markdown_to_qt_html` 安全清洗后展示）。修复了一处状态跟踪 bug（开/闭标签切换误判），自测 `流式解析思考块 / 答案块` 通过。

### 2.5 隐藏导入完整 — ✅ 通过

`starrystar.spec` 新增 `core.memory` / `core.reasoning` / `ui.memory_dialog`，PyInstaller 构建无 `ModuleNotFoundError`（见《项目结构与提交指南_v8_0.md》第 4 节实构建验证）。
