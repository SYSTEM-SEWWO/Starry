# 代码评审 · 星语 Starry v7.2 → v7.3（GitHub 开发者视角）

> 评审人：以 GitHub 开源维护者 / OSS Reviewer 身份
> 评审对象：`ai-assistant/` v7.2 工作区（601 项自测、21 家服务商）
> 评审目的：在启动 v7.3「毛玻璃 · 商业版」之前，定位真实、可复现的工程问题，给出 `文件:行` 级修复方案。

---

## 结论速览

| 等级 | 数量 | 说明 |
| --- | --- | --- |
| **P0（正确性 / 信任）** | 2 | 版本号不一致、缺 EULA/商业授权 |
| **P1（体验 / 视觉硬伤）** | 3 | 真·毛玻璃缺失、动画句柄泄漏、常驻定时器空转 |
| **P2（质量 / 健壮性）** | 3 | 字体硬编码、圆角令牌偏小、PluginCard 无样式 |
| **P3（整洁 / 可维护性）** | 4 | 冗余 import、循环内重复 import、selftest 定时器风险、GlowOrb 缺可见性守卫 |

总体评价：**架构分层清晰（core / app / ui 权责分明），自测覆盖率高是加分项**；但在「玻璃质感真实性」「资源空转」「商用合规」三处与 v7.3 目标（毛玻璃 + 企业商用）存在硬缺口，必须在本轮补齐。

---

## P0-1 · 版本号与文档严重不一致（信任问题）

- **证据**：`core/config.py:16` 中 `APP_VERSION = "3.0.0"`，而 `README.md` / `CHANGELOG.md` 通篇称 v7.2.0，`关于`对话框（`ui/about_dialog.py:67,80,193`）直接显示 `APP_VERSION`。
- **影响**：用户/企业客户在「关于」页看到 `v3.0.0`，与发布说明的 v7.2 矛盾，损害专业可信度；自动更新比对、技术支持都基于错误版本。
- **修复**：统一推进为 `7.3.0`（本轮），并在 `config.py` 增加 `APP_VERSION` 单一真相源校验注释；CI 增加断言 `APP_VERSION` 与 `CHANGELOG` 最新小节一致。

## P0-2 · 缺少 EULA 同意门与商业授权信息（合规缺口）

- **证据**：全仓无首次运行许可同意、无 `accepted_eula` / `license_key` 字段；`LICENSE` 仅为 MIT；关于页无版权/授权类型/密钥占位。
- **影响**：产品明确走向「企业商用」，但无许可同意流程与授权声明，分发即存在合规风险。
- **修复**：新增 `ui/eula_dialog.py`（首跑同意门，拒绝则退出）；`core/config.py` 增加 `accepted_eula` / `license_key`；重写 `LICENSE` 为商业许可；关于页新增「商业授权」状态块与 `© 2026 星语 Starry`。

## P1-1 · 「毛玻璃」是伪玻璃：仅半透明纯色填充，未对窗后内容模糊

- **证据**：`ui/liquid.py:149-153` 的 `LiquidGlass.paintEvent` 仅用 `base.setAlphaF(0.86 if dark else 0.94)` 做半透明实色填充；`ui/theme.py` 的 `liquid_dialog_qss` 同理用 `rgba(title_bg, 0.55)`。两者都没有抓取并模糊窗后像素，因此不是真正的 frosted / backdrop-blur。
- **影响**：用户本轮明确要求「UI 都要毛玻璃」。当前在有内容的桌面/窗口背后，玻璃面板只是「半透明白板」，缺乏真实折射/磨砂质感，与 Apple 液态玻璃 / Windows 11 Mica 观感差距明显。
- **修复**：新增 `ui/frost.py` 的 `FrostGlass(QFrame)`——`show/move/resize` 时抓取屏幕对应区域、降采样、高斯模糊、圆角合成、叠加主题 tint + 顶高光 + 1px 亮边 + 环境光晕；offscreen/headless 走 faux 降级（渐变 + 噪点）。顶层对话窗 / 划词窗 / 关于 / EULA 改用 `FrostGlass`，内层小组件保留轻量 `LiquidGlass`。

## P1-2 · 动画句柄泄漏：`_val_anim` 重触发不停止旧动画

- **证据**：`ui/liquid.py:66-79` 的 `_val_anim` 每次调用都 `QVariantAnimation(parent)` 新建，**从不 `stop()` 旧动画**。调用方 `animate_glow` / `animate_sheen`（`liquid.py:117-138`）、`MetricRing.set_value`（`liquid.py:397`）、`NumberRoll.set_target`（`liquid.py:595`）、`Sparkline.set_data`（`liquid.py:501`）均会反复触发。
- **影响**：`LiquidCard` 频繁 hover 进出 → 多个动画竞争同一属性 → 抖动/跳变；旧动画对象直到 `DeleteWhenStopped` 才回收，临时内存泄漏。
- **修复**：每个动画类持有 `_anim` 句柄，重触发前 `stop()`；加入防御性 `RuntimeError` 捕获（已有）。

## P1-3 · 常驻 33/60ms 定时器空转（隐藏/最小化也在重绘）

- **证据**：`GlowOrb`（`liquid.py:245-247` 33ms）、`StatusDot`（`liquid.py:327-330` 60ms）、`Sparkline`（`liquid.py:484-486` 200ms）、`SplashWindow`（`splash.py:80-82` 33ms）、`FloatingBall`（`floating_ball.py:195-197` 33ms）的定时器**无可见性守卫**，即使窗口 `hide()` / 最小化仍持续 `update()`。
- **影响**：CPU 空转、笔记本发热、合盖耗电；多对话框同时开时叠加更明显。
- **修复**：`paintEvent` 外对 `isVisible()` 短路；`FrostGlass` 提供 `pause()/resume()`；`GlowOrb` 等加 `setVisible` 守卫。`offscreen` 自测下定时器不应拖累计数。

## P2-1 · 开屏/关于字体硬编码 `Microsoft YaHei`

- **证据**：`ui/splash.py:400,419` `QFont("Microsoft YaHei", ...)`；关于页依赖系统默认。
- **影响**：Linux/macOS 无该字体时回退不可控，开屏标题中文可能方块或字重错乱；与产品「跨平台」定位冲突。
- **修复**：统一使用 `ui.theme.GLOBAL_FONT` 回退链（雅黑 / 苹方 / Noto CJK SC）；`splash.py` 标题与副标题改用该字体族。

## P2-2 · 圆角令牌偏小，与「资深美术师 / 圆角」诉求有差距

- **证据**：`ui/theme.py:19-21` `RADIUS_S/M/L = 8/12/16`。
- **影响**：现代玻璃风（Apple / Windows 11 / 主流 SaaS）普遍 10/14/20+；当前偏「硬」，影响高级感。
- **修复**：`8/12/16 → 10/14/20`；`build_qss` / `liquid_dialog_qss` 已参数化，自动生效；毛玻璃基底默认用 `RADIUS_L=20`。

## P2-3 · 关于页卡片 `objectName("PluginCard")` 实际无样式

- **证据**：`ui/about_dialog.py:121,156` 用 `card.setObjectName("PluginCard")`，但 `PluginCard` 的样式仅在 `ui/market_dialog.py:228` 的局部 QSS 中定义，关于页未引入 → 卡片继承默认 QSS，视觉与「插件市场」不一致。
- **修复**：关于页卡片改用 `LiquidGlass` / `FrostGlass`，与全站玻璃语言统一。

---

## P3-1 · 冗余 import：`random` 重复引入

- **证据**：`ui/floating_ball.py:12` 顶部 `import random`，又在 `_start_roam`（`floating_ball.py:316`）内 `import random as _rnd`。
- **修复**：删除函数内重复 import，复用顶部 `random`。

## P3-2 · 循环/频繁路径重复 import

- **证据**：`floating_ball.py:334` `_pop_tip` 内 `import datetime as _dt`、`:317` 内 `import random as _rnd`；`assistant.py:1160` `export_conversation` 内 `import datetime`；`assistant.py:791` `_on_failed` 内 `import html`。
- **修复**：统一提到模块顶部（或函数外），避免每次调用重复导入开销。

## P3-3 · `selftest.py` 定时器组件风险

- **证据**：`GlowOrb` / `StatusDot` / `Sparkline` 在 `selftest` 构造即 `start()` 定时器；offscreen 无事件循环驱动时虽不报错，但增加测试不确定性。
- **修复**：自测对这些组件用 `QTimer.singleShot` 触发一次 `update()` 即可，避免常驻定时器；或给组件加 `pause()` 在测试首尾调用。

## P3-4 · `GlowOrb` 缺少可见性守卫（与 P1-3 同源）

- **证据**：`liquid.py:245-247` 定时器无条件 `update()`。
- **修复**：增加 `if not self.isVisible(): return` 守卫（见 P1-3）。
