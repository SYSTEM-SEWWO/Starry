## 2. REA（Reverse Engineer Anything）复刻方案

**目标仓库**：`github.com/morluto/rea`（MIT，TypeScript，2026-10 GitHub Trending 爆火，17 万+ Star）。

**REA 是什么**：一个 **MCP 服务器**，把 Hopper / Ghidra / IDA / Apktool 等逆向工具封装为 AI Agent 可调用接口，做
「**证据驱动、本地优先、Agent 驱动**」的全链路逆向分析。它不是反编译器，而是 AI Agent 与专业逆向工具之间的桥梁。

**能力面（已抓取 README / 文件树核对）**：
- 支持目标：原生二进制(ELF/PE/Mach-O)、Electron/JS、Android APK、.NET、网站/HAR、固件/GGUF/safetensors 等；
- 40+ 工具（如 `binary_overview`、`batch_decompile`、`get_call_graph`、`inspect_pe_imports`、`analyze-javascript-application`）；
- 工作流：总览 → 追踪字符串/交叉引用/调用图 → 取伪代码与汇编 → 在己方项目重建；每条结论附**证据 + 局限**；
- 多引擎容错、compact schema 降上下文开销、静态优先不上传二进制。

**「复刻 REA 功能写入本项目」的落地方式（最忠实且可行）**：
REA 本身即「给 Agent 用的 MCP 服务器」，因此星语作为 Agent 宿主，**以既有 MCP 生态接入 REA**：
- `core/rea.py`：REA 的 MCP 预设、分析目标清单、`build_rea_prompt()` 证据驱动提示、`ensure_rea_preset()` 去重并入；
- 设置页 MCP 区「🔍 添加 REA 预设」一键接入（`ui/settings_dialog.py:1091 _on_mcp_add_rea`）；
- 命令面板 `rea` 入口（`app/assistant.py:480 / 1088 open_rea`）；
- 底层二进制引擎（Ghidra/IDA）由用户按 REA 官方要求自备——与 REA 自身设计一致：星语负责编排与呈现，REA 负责底层拆解。
