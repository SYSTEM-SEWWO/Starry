# 用户使用指南 · 星语 Starry v6.1

> 面向第一次拿到这个项目的用户。目标：10 分钟内完成第一次对话。
> 完整功能清单见 `README.md`；本文只讲「怎么用、怎么选、遇到问题怎么办」。

---

## 一、10 分钟快速开始

### 第 1 步：安装依赖（约 2 分钟）

```bash
cd ai-assistant

# 方式一：一键启动脚本（自动建 venv 装依赖，推荐）
./启动.sh                # macOS / Linux
启动.bat                  # Windows

# 方式二：手动
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

首次启动会看到液态玻璃开屏动画 → 新手引导（10 步，可跳过）。

### 第 2 步：选一种方式接入模型（三选一，可同时配置）

| 方式 | 适合谁 | 配置成本 | 费用 |
| --- | --- | --- | --- |
| **A. DeepSeek 网页版** | 不想申请 Key 的人 | 首次扫码登录一次 | 免费（网页版额度） |
| **B. 本地模型** | 隐私优先 / 离线使用 | 下载 GGUF（模型库一键下载） | 免费（占磁盘/内存） |
| **C. 云端 API** | 要稳定速度 / 多服务商 | 填 API Key | 多数服务商有免费额度 |

**最省事路径**：什么都不配 → 单击悬浮球 → 模型下拉框选「DeepSeek 网页版」→
按提示完成一次登录 → 直接提问。登录态持久化，之后永久免 Key。

### 第 3 步：开始对话

- **单击悬浮球**展开聊天窗，输入框打字，Enter 发送；
- **深度思考**：点标题栏 🧠 切换到推理模型，思考过程实时折叠展示；
- **多模态**：输入框 📎 传文件/图片，✂ 框选屏幕区域截图提问；
- **快捷操作**：`Ctrl+K` 命令面板（20 个功能键盘可达）、全局热键唤出悬浮球。

## 二、三种接入方式详解与选择建议

### A. 网页版接入（v6 头号功能，免 Key）

1. 模型下拉框选「DeepSeek 网页版」→ 若未就绪，按提示去
   **设置 → 网页接入** 点「⬇ 一键安装浏览器内核」（约 150MB，一次性）；
2. 点「打开登录页」或在命令面板选「🌐 登录 DeepSeek 网页版」，
   在弹出的浏览器里扫码/账号登录一次；
3. 回到聊天窗直接提问——程序像人一样操作网页，回答逐字流式返回。

**适用**：免费额度用、R1 深度思考、联网搜索（网页版都自带）。
**注意**：依赖网页结构，站点大改版时可在 `config.json` 的
`web_deepseek.selectors` 覆盖选择器（逃生舱）；多轮对话以「前情提要」
形式拼接发送。

### B. 本地模型（完全离线）

1. **设置 → 本地模型**：放置 llama.cpp 二进制，或从
   **模型库（📦）** 搜索阿里魔塔 GGUF 一键下载（Q4_K_M 推荐，4–6GB）；
2. 模型下拉框选「Ollama」「LM Studio」或「魔塔本地模型」；
3. 首次加载约 10–60 秒（取决于磁盘与内存），之后常驻。

**适用**：隐私敏感、无网环境、长文处理。
**注意**：7B 模型建议 ≥ 16GB 内存；视觉问答需本地视觉模型。

### C. 云端 API（19 家服务商）

1. **设置 → 服务商**：选服务商（智谱/硅基流动/DeepSeek/OpenRouter/Groq/
   Moonshot/MiniMax/腾讯混元/百度千帆/Together/Mistral/Perplexity/Azure/
   阿里百炼等），粘贴 API Key；
2. 点「测试连接」验证；
3. 模型下拉框选择具体模型；**思考强度**（reasoning.effort）、
   **上下文大小**、温度等参数在「生成参数」页调整，支持按模型级覆盖。

**免费起步推荐**：智谱 GLM-4-Flash、硅基流动、Groq、DeepSeek（低价）。

## 三、网关仪表盘（🛰 多服务商运维中枢）

命令面板输入 `gateway` 或托盘「🛰 网关仪表盘」打开：

| 区域 | 看什么 | 怎么用 |
| --- | --- | --- |
| 顶部指标环 | 全局成功率 / 今日请求 / 平均延迟 / 估算 token | 一眼判断整体健康度 |
| 服务商卡片 | 每家通道的今日用量、延迟、状态灯 | 点卡片看下方详情 |
| 详情区 | 60 分钟延迟折线 + 密钥池 | **多 Key 轮询**：添加多个 Key，失败 2 次自动冻结 120s 后恢复 |
| 健康检查 | 「🩺 健康检查」按钮逐家探活，带 n/19 进度 | 配置完 Key 后跑一次，确认都活着 |
| 路由策略 | 自动 / 最低延迟 / 手动指定 | 「最低延迟」会自动把请求切到最快的服务商 |

**典型用法**：手里有 3 个服务商的 Key → 全部填进密钥池 → 策略选「自动」→
程序轮询使用、失败自动退避，你在仪表盘上看谁快谁慢。

## 四、典型场景配方

| 场景 | 配置 |
| --- | --- |
| 完全免费 | 网页版（DeepSeek）+ 智谱 GLM-4-Flash + 本地 7B，三路互为备份 |
| 完全离线 | 本地模型 + 资料库（导入文档检索引用），不配任何 Key |
| 联网问答 | Perplexity API，或网页版（自带联网搜索） |
| 长文档分析 | 上下文大小调至 128K（Moonshot/阿里百炼）+ 资料库导入 |
| 多 Key 抗限流 | 网关密钥池添加同服务商多 Key，策略「自动」 |
| 自动化盯盘/日报 | 自动化任务：定时/间隔执行提示词，结果进会话 |

## 五、故障排查速查

| 现象 | 原因与解决 |
| --- | --- |
| 提示「未安装 Playwright」 | 设置 → 网页接入 → 一键安装浏览器内核 |
| 网页版提示未登录 | 命令面板选「🌐 登录 DeepSeek 网页版」完成登录 |
| 网页版回答抓取为空 | 站点改版：在 `config.json` 的 `web_deepseek.selectors` 更新选择器；或临时切回 API |
| 请求 401/403 | Key 错误或过期：设置 → 服务商 → 重新粘贴 → 测试连接 |
| 一直转圈无响应 | 仪表盘「🩺 健康检查」看该服务商状态；本地模型检查 llama.cpp 是否启动 |
| 思考过程不显示 | 当前模型非推理模型：切到 DeepSeek-R1 / QwQ 等，或开 🧠 深度思考 |
| TTS 没声音 | `pip install pyttsx3`（可选依赖）；Linux 需 espeak |
| 全局热键失效 | `pip install pynput`；Linux Wayland 下热键可能受限，用 Ctrl+K 代替 |
| 想重置全部配置 | 删 `config.json` 后重启（会话在 `sessions.json`，可分别保留） |

配置文件位置：`~/.config/ai-desktop-assistant/config.json`
（Windows：`%APPDATA%\ai-desktop-assistant\`，macOS：`~/Library/Application Support/ai-desktop-assistant/`）。
网页版登录态在浏览器 profile 目录（默认 `~/.starry/browser/deepseek`）。
会话、统计、网关数据均在本地，不上传任何服务器。

## 六、打包分发给别人

```bash
# 三平台一键打包（需先 pip install pyinstaller）
scripts/build_linux.sh      # Linux 单文件
scripts/build_macos.sh      # macOS .app
scripts/build_windows.ps1   # Windows exe
```

**安装包边界（重要）**：安装包**不含**浏览器内核（约 150MB）与 llama.cpp，
对方首次使用网页版/本地模型时按产品内指引一键安装即可——这是有意设计，
安装包保持轻量。源码运行用户无此限制。

## 七、自测与二次开发

```bash
QT_QPA_PLATFORM=offscreen python3 selftest.py        # 463 项自测 + 重新生成 docs/ 截图
python3 verify_v6_browser.py                          # 12 项网页版端到端（需 Chromium）
```

想改网页版适配（站点改版时）：编辑 `core/web_deepseek.py` 的选择器，
或直接用 `config.json` 覆盖，无需改代码。架构分层（app/core/ui）与
评审文档见 `docs/` 目录。
