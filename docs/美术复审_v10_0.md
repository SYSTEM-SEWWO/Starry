# 美术复审 · V10.0

> V10.0 的视觉增量主要在「无界面命令行版」的**文字呈现质感**与**版本分发视觉一致性**上，
> 桌面 GUI 的毛玻璃/微光/液态玻璃（V9.0 已落地）保持不变。

## 1. 命令行版视觉表达

- 思考过程以「【思考过程】」分区呈现，与正文留出空行节奏，阅读层次清晰。
- 工具事件以 `[工具] 名称(参数) → 结果` 单色等宽呈现，信息密度高且不花哨。
- `--json` 提供结构化输出，满足「机器可读性」这一隐形审美（一致性 > 装饰）。

## 2. 版本分发视觉一致性

- 各平台文件夹统一以「星语Starry-v10.0-<后缀>」命名，主视觉（README 头图、
  图标 `assets/icon.*`）在每包复用，保证品牌一致。
- 后缀语义清晰（windows-cli / linux-cli / uos / android），用户一眼可辨平台归属。

## 3. 与 V9.0 视觉体系的衔接

- 桌面端：液态玻璃字幕卡 + 微光扫掠（V9.0 `ui/floating_ball.py`）继续作为「思考可视化」旗舰表达；
- 命令行端：以**文字节奏 + 结构分层**达成「无界面下的思考可见」，与桌面端理念同源。

## 4. 建议

1. 可为命令行版在 CI 中生成「终端截图/录屏」作为发布素材，与桌面端截图同列于 README。
2. 各平台指南建议配一张「该平台运行效果图」（如 Termux 截图、UOS 终端截图）。

## 5. 评分：**A-**（视觉增量克制、与既有体系同源；缺终端端视觉素材）
