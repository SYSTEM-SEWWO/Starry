# 美术复审 · V11.0

> 评估视觉一致性、移动端适配、品牌传达。V11.0 新增**安卓原生界面**，需确认与桌面「液态玻璃」语言对齐。

## 1. 品牌一致性

- 安卓图标（`resources/starryandroid.png`）沿用品牌翠绿（`#10b981`）+ 四角星 + 双层光环，
  与桌面 icon、开屏、悬浮球同源，视觉资产统一。
- 标题栏「✦ 星语 Starry · 11.0.0」延续桌面「✦」符号体系，识别连贯。

## 2. 移动端视觉映射

| 桌面元素 | 安卓映射 | 评价 |
|---------|---------|------|
| 液态玻璃悬浮球（思考态） | 思考卡片（`#ecfdf5` 浅绿底 + 微光文字） | 受 Toga 控件限制，以「浅底 + 实时文字流」还原「动态思考」观感，方向正确 |
| 流式回答气泡 | 左对齐「星语：」/ 右对齐「我：」文本 | 移动端以对话式文本为主，清晰可读 |
| 工具调用回显 | `[工具] name → result` 琥珀色小字 | 保留「证据可见」的设计语言 |

## 3. 交互与可读性

- 深色/浅色主题在安卓端暂用系统默认（Toga 受平台约束），后续可接 `appearance.theme`。
- 思考卡片以 `visibility` 切换，避免空占空间；滚动自动置底，长对话不迷路。

## 4. 不足与建议

1. Toga 在安卓暂不支持圆角/阴影等「液态玻璃」细节，思考卡片的「玻璃质感」仅以浅色块近似；
   若需 1:1 还原，可后续改用 BeeWare 的 `WebView` 承载 HTML/CSS 液态玻璃组件。
2. 建议补充启动闪屏（Splash）与空状态插画，弱化「纯文本」的朴素感。

## 5. 评分：**B+**（品牌统一、移动端映射合理；玻璃质感受框架限制为近似实现）
