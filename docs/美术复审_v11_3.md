# 美术复审 · v11.3.0

> 维度：视觉一致性、交互质感、与既有设计语言（翠绿 + 白主体 / 液态玻璃）的协调。

## 1. 收藏夹对话框

- 沿用会话管理框的卡片样式：`#fafbfc` 底色、`1px #e3e8ef` 描边、选中态 `#e6f2ff`，**视觉语言一致**，不引入新配色。
- 列表项含「会话标题 / 角色徽标 / 摘要片段」，信息密度与现有列表对齐。

## 2. 命令面板

- 新增四条命令沿用 emoji 图标体系：⭐ 收藏 / 📌 收藏夹 / 📋 总结 / 📦 导出，与既有 📝 导出同组，**不破坏面板排版与对齐**。
- 分组（对话 / 文件）延续既有归类逻辑。

## 3. 安卓端

- 错误窗口复用 Toga 原生控件与 `direction="column"` 布局，未引入自定义绘制，跨设备字体 / 间距由系统主题托管，**不破坏原生观感**。

## 4. 一致性结论

- 无新增配色、无突兀控件，新增界面与既有设计系统同源。
- 建议（非阻塞）：收藏夹可对「角色」用色块（用户蓝 / AI 绿）做轻量区分，进一步降低扫读成本。

**结论**：视觉一致，美术复审通过。
