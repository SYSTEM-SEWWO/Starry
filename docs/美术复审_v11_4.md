# 美术复审 · v11.4.0

> 视角：视觉一致性 / 排版 / 交互反馈。评审对象：消息选择器 `MessagePickerDialog` 与命令面板新增项。

## 1. 对话框样式一致性
- `ui/message_picker_dialog.py` **完全沿用** v11.3 收藏夹 / 会话管理框的 `QListWidget` 卡片样式：`#fafbfc` 底、`1px #e3e8ef` 边、`10px` 圆角、选中 `#e6f2ff`、hover `#f0f6ff`、逐行 `1px #eef1f5` 分隔。
- 标题 `14px / 600 / #16293c`、提示 `12px / #5b7086`、输入框 `1px #d8e0ea` 圆角，均与现有设置/对话框同一套配色与字阶。
- 底部「取消 / 确定」按钮条 `addStretch(1)` 右对齐，与收藏夹布局一致，无新增视觉范式。

## 2. 一框两用的克制设计
- 引用 / 分支**共用一个对话框**，通过标题（💬 / 🌿）、提示文案、是否显示追问输入框区分，避免新增两套界面造成风格漂移与维护负担。
- 引用模式的追问输入框带中文占位提示（"例如：那它和经典计算到底有什么区别？"），比空输入框更友好，降低认知负担。

## 3. 引用块的呈现
- 引用块用标准 Markdown `> ` 前缀组织（多行逐行加前缀），在气泡中天然呈现为「引用」语义，无需额外 UI 控件。
- `> 【引用 #2 · 助手】` 头部标明下标与角色，用户能一眼看出引用自哪条消息，信息层级清晰。

## 4. 命令面板排版
- 新增图标沿用 emoji 体系（💬↩️🌿🌱），归入「对话」组，与既有 ⭐📌📋 收藏/总结同组，四行说明文案长度控制在既有范围内，不破坏面板行高与对齐。

## 5. 交互反馈
- 无可选消息时 `hint` 提示「当前会话还没有可选择的消息」；未选就点确定提示「请先选择一条消息」；分支成功 / 引用成功均有 `show_hint` 反馈；空分支列表弹出引导 `QMessageBox`——全路径无静默空白态。

**结论**：v11.4.0 未引入任何新视觉语言，复用既有卡片样式与 emoji 体系，一框两用克制，交互反馈完整，视觉一致性通过。
