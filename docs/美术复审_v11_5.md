# 美术复审 · v11.5.0

**视角**：视觉一致性、信息层级、可读性与降级表现。

## 1. 新增组件：`ui/insight_dialog.py`

| 检查项 | 评价 |
|---|---|
| 样式继承 | 圆角 10px、`#fafbfc` 背景、`#e3e8ef` 描边、`#16293c` 标题色，与 `message_picker_dialog.py` / `starred_dialog.py` 完全一致 |
| 布局 | 顶部说明 → 中部只读区（`QTextBrowser`，占满伸展位）→ 底部按钮栏（复制 / 另存 / 关闭），符合既有对话框骨架 |
| 尺寸 | 700×580，能容纳「单会话表 + 全局概览表」不出现拥挤滚动 |
| 交互 | 「复制内容」「另存为 .md」两个次级动作 + 「关闭」默认按钮，主次分明 |

## 2. 内容呈现（Markdown 渲染）

- `format_stats_markdown` 用两张三列表格分区（当前会话 / 全局概览），
  `format_diff_markdown` 用「元信息表 + 分节列表」，层级清晰。
- 差异项里 A/B 两行缩进对齐，长文本按 `max_chars` 截断并加省略号，
  避免面板被单条超长回复撑破。
- 相似度以百分比展示、共同前缀以条数展示，比裸浮点更友好。

## 3. 降级与兼容

- `setMarkdown` 外层有 `try/except`，老版本 PyQt5 自动退化 `setPlainText`
  ——**不会因为渲染 API 缺失而崩溃**（延续 v11.3 起「不静默崩」的设计原则）。
- 纯英文代码页下 exe 中文退化为 `?` 属控制台限制，GUI 桌面端不受影响。

## 4. 命令面板图标

新增 📊 / 🔀 / 🧬 三个图标，与既有「⭐ 收藏 / 📌 收藏夹 / 📋 总结 /
💬 引用 / 🌿 分支」形成连贯的语义序列：统计（看）、对比（比）、合并（合）。
分组仍归「对话」，不新增分组，列表不显杂乱。

## 5. 建议

- 后续可把「相似度」做成一条细进度条，进一步可视化（当前百分比文字已足够）。
- 对比结果中 A/B 若能用左右双栏而非上下两行，长文本对照会更省力。

## 结论

**通过**。视觉语言统一、信息层级清楚、降级路径完整，无新增视觉债。
