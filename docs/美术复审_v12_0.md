# 美术复审 · v12.0.0

**视角**：视觉一致性、信息层级、可访问性、降级表现、跨端观感统一。

---

## 1. 安卓端首次有了明确的主题令牌

v11.5 的安卓界面是散落的颜色字面量；v12.0 在
`android/starryandroid/app.py` 顶部收敛成 `PALETTE`，两套主题与桌面
`ui/theme.py` 的 light / dark 主色对齐：

| 令牌 | light | dark | 用途 |
| --- | --- | --- | --- |
| `bg` | `#ffffff` | `#101827` | 页面底色 |
| `text` | `#111827` | `#f3f4f6` | 正文 |
| `muted` | `#4b5563` | `#9ca3af` | 次要信息 |
| `accent` | `#0eaf7e` | `#2dd4a7` | 主强调色（延续星语绿） |
| `think_bg` / `think_fg` | `#ecfdf5` / `#0f766e` | `#052e2b` / `#5eead4` | 深度思考分片区 |
| `bubble_user` / `bubble_ai` | `#dcfce7` / `#f3f4f6` | `#134e4a` / `#1f2937` | 对话气泡 |
| `tool` / `error` | `#92400e` / `#b91c1c` | `#fbbf24` / `#fca5a5` | 工具调用 / 错误 |

评价：

- 深浅两套都保持「用户气泡偏绿、AI 气泡偏中性」的语义，跨主题不换含义；
- 深色下 `error` 从 `#b91c1c` 提到 `#fca5a5`，在 `#101827` 底上有足够对比度，
  不是简单把浅色值搬过去；
- `think_bg / think_fg` 成对定义，避免「思考区背景变了但字没变」的可读性事故。

## 2. 字号档位（可访问性）

```python
FONT_SCALES = {"标准": 1.0, "大": 1.15, "超大": 1.3}
```

设置页可选三档，作用于界面字号。这是本轮对**移动端可访问性**最实际的一步：
手机屏幕小、用户年龄层跨度大，固定字号在小屏上常常不可用。
档位命名用中文「标准 / 大 / 超大」而非 `1.0 / 1.15 / 1.3`，用户不需要理解倍率。

`_safe_value()` 会先校验当前配置值属于选项列表，再赋给 `Selection`——
这既是 F3 的崩溃修复，也避免了「设置页一打开就是空选中态」的视觉异常。

## 3. 信息层级：把「闪退」变成一张看得懂的卡片

| 页面 | 层级设计 |
| --- | --- |
| 聊天页 | 系统欢迎语 → 消息气泡（`Box(children=[Label])`，用户 / AI / 工具 / 错误语义分色）→ 输入区 + 停止按钮 |
| 设置页 | 服务商 / 模型 / API Key / 主题 / 字号 / 深度思考 / 智能体，主窗口内容切换，**不新开窗口** |
| 诊断页 | 版本号 → 平台 → 配置目录 → 异常条数 → 可复制日志 |
| 致命错误页 | 启动失败时显示错误摘要与排查提示，而不是黑屏退出 |

过去「闪退后什么也看不到」，现在至少有一张写着原因的页面。
从视觉设计角度看，这是**把不可见的系统失败转成可见的信息卡**，
比加装饰元素更有价值。

`ActivityIndicator` 与「停止」按钮构成忙碌态的前后呼应，
配合 `_throttled()` 每 80ms 节流，流式输出不会把界面刷到卡顿或闪烁。

## 4. 跨端一致性：星尘卡

`✦ 星尘卡` 是一份**纯 Markdown 文本**，由 `core/stardust.py::build_echo_card`
生成，桌面弹窗、CLI stdout、安卓气泡用的是**同一份排版**：

```
✦ 星尘卡
**本轮问答**
- 思考起点 / 思考落点 / 答
> 思考分片 N · 约 N tokens · 分支锚点
```

好处是三端不会出现「PC 上叫思考卡、手机上叫摘要」的口径漂移；
代价是卡片在 GUI 里不是富组件（无独立配色块）。
考虑到它要能被复制进任意笔记软件，**纯文本是正确取舍**。

桌面命令面板新增 5 个图标 `✦ 📐 📤 📥 🩺`，
与既有 `⭐ 📌 📋 💬 🌿 📊 🔀 🧬` 组成连贯的语义序列，
仍归在原有分组内，没有新增分组、没有打乱列表节奏。

## 5. 降级与兼容表现

| 场景 | 降级行为 | 视觉影响 |
| --- | --- | --- |
| `stardust` 在安卓端导入失败 | `app.py` 里 `try/except` → `stardust = None` | 不附星尘卡，主流程照常，不弹错误框 |
| 配置写 `theme` / `font_scale` 为非法值 | `PALETTE.get(..., PALETTE["light"])`、`FONT_SCALES.get(..., 1.0)` | 回落到 light / 标准，不出现无样式界面 |
| `Selection` 的当前值不在选项里 | `_safe_value()` 回落到第 0 项 | 永远有选中态，不空白 |
| `vertical_position` 属性不可用 | `_scroll_bottom()` 再尝试 `scroll_to_bottom()`，最后静默放弃 | 最坏情况是不自动滚动，不崩 |
| 启动异常 | 应用内错误页 | 有可读原因，非黑屏 / 非直接退出 |

「降级后仍保持基本视觉完整性」这几条都做到了，延续了 v11.3 起
「不静默崩」的设计原则。

## 6. 建议（不阻塞发布）

| 建议 | 理由 |
| --- | --- |
| 真机截图复核深浅两套主题 | 色值在桌面设计稿上对比度合理，但 Android 系统字体 / 深色模式 / 全面屏裁切需设备确认 |
| 主题跟随系统切换 | 当前依赖应用内 `theme` 配置，未监听系统夜间模式变化 |
| 星尘卡在 GUI 可做轻量富展示 | 保留可复制纯文本的同时，加一个等宽卡片容器与 `✦` 图标 |
| 诊断页加「一键复制」按钮 | 目前日志可读可复制，但移动端长按选择文本体验一般 |
| 大字号档位下检查长按钮文案 | 1.3 倍时部分中文按钮可能换行，需真机验证 |

---

## 结论

**通过**。v12.0 让安卓端第一次有了与桌面对齐的主题令牌、三档字号与
分色气泡语义，并把「闪退」这一最糟糕的视觉体验改造成可读的错误页与诊断页。
跨端共用的星尘卡排版保证观感一致，降级路径完整无空白态。
剩余建议集中在真机复核，不阻塞发布。
