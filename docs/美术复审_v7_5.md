## 3. 待打磨（按性价比排序）

### P1 · 玻璃「厚度感」略薄 → 已落地 ✅
- **问题**：当前只有顶部高光，缺少底部内阴影，玻璃显得"贴"在背景上而非
  "浮"着，少了高端系统的纵深。
- **修复**：`frost.py:paintEvent` 增加底部内阴影渐变（`0→26/14` 黑），
  立即获得厚度。零布局成本、零新依赖，自测仅验证可绘制，安全。

### P2 · 亮边在浅色主题偏弱
- **问题**：浅色主题下 `edge` 用 `border⊕accent` 混合，对比不足，玻璃边界
  易与白背景糊在一起。
- **建议**：浅色主题亮边 alpha 从当前基线提升到 `70–90`，或加 0.5px 外发光。
  下轮做（需重测四主题对比度）。

### P3 · 开屏星尘可加入「景深虚化」
- **问题**：46 颗星尘均匀清晰，缺乏焦外粒子，空间层次还可更强。
- **建议**：对最远 depth 层星尘叠加轻微模糊（半径 1–2px），强化 parallax。

### P4 · 主色单一，缺少「第二强调色」
- **问题**：全站几乎只有一个 accent（翠绿），长时间使用略单调。
- **建议**：在极光/光晕中引入 `aux` 辅色做冷暖对撞（已在 `theme.BRAND`
  预留 `aux`），提升奢华感。

## 4. 一致性核查

- 四主题（light/sky/dark/sky_dark）均复用同一套令牌，未出现硬编码色值
  残留（v7.3 已修 `QColor` 混用问题）。
- 关于页、EULA、设置页、聊天窗统一使用 `FrostGlass`/`LiquidGlass`，
  玻璃语言一致。
- 字体统一 `GLOBAL_FONT` 家族，无平台硬编码回退崩溃风险（v7.3 已修）。
