# 美术复审 · v8.0 —— 视觉与交互评估

> 评审视角：资深美术 / 体验设计。评估 V8.0 新增记忆入口、记忆对话框，以及深度思考呈现增强的视觉一致性。
> 评级：**A-**。

---

## 1. 新增视觉元素清单

| 元素 | 位置 | 设计要点 | 证据 |
| --- | --- | --- | --- |
| 记忆按钮 🧠 | 标题栏（资料库按钮右侧） | 复用 `FlatButton` 令牌，30×30，悬停手型；带实时计数角标 `🧠N` | `ui/chat_window.py:166` |
| 计数角标 | 同按钮 | 随记忆条数更新（`set_memory_count:635`），零条显 `🧠0`，引导用户「聊几句就被记住」 |
| 记忆对话框 | 模态弹窗 | 沿用液态玻璃质感容器；分类小标题 `SectionLabel`；每行「忘记」按钮；底部「清空全部 + 关闭」 | `ui/memory_dialog.py` |
| 思考块增强 | 聊天气泡内 | 原思考块已支持折叠 + 用时；V8.0 把**藏在 `<think>` 里的思考**也剥离进同一折叠块，呈现更干净 | `core/reasoning.py` + `app/assistant.py:730/768` |

## 2. 视觉一致性检查

- ✅ 记忆按钮复用既有 `FlatButton` 与 `setObjectName`，主题色随 `theme.py` 令牌，无硬编码。
- ✅ 记忆对话框沿用 `FrostGlass` 玻璃容器与现有排版间距（12/14/16 节奏），与关于页 / 资料库页同源。
- ✅ 思考内容走既有 `markdown_to_qt_html` 安全渲染，字体 / 圆角与正文一致。

## 3. 待优化（非阻断）

| 项 | 建议 | 优先级 |
| --- | --- | --- |
| 记忆角标在「0 条」时略显空 | 零条时改为 `🧠` 无数字，hover 提示「聊几句，星语就会记住你」 | P3 |
| 记忆对话框可加空状态插画 | 当前为空状态纯文字，可配一个极简 🧠 玻璃图标提升温度 | P3 |
| 思考块「用时」精度 | 流式思考已有时长统计，建议 V8.1 增加「思考 X 字 / 用时 Ys」双指标 | P4 |

## 4. 美术结论

V8.0 的新增视觉元素**全部落在既有设计系统之内**，未引入新的色彩 / 圆角 / 动效方言，体验连贯。深度思考呈现因「内嵌思考剥离」而更干净，是「看不见但感受得到」的提质。

**评级：A-**（视觉体系稳；角标零态与空状态插画建议留 v8.1 收尾，不影响发布）。
