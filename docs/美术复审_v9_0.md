# 美术复审 · 星语 Starry V9.0

> 视角：视觉语言一致性、动效质感、信息层级、品牌调性。

## 1. 深度思考可视化（本轮重点）

- **悬浮球 THINKING 态升级**：在 V8.0 的旋转弧 / 双轨道粒子 / 脉冲波纹之上，新增**液态玻璃折射高光 + 微光扫掠**覆盖层（`ui/floating_ball.py:672 _paint_glass_overlay`）——旋转锥形高光模拟玻璃折射，循环亮带模拟微光，质感更「果冻 / 液态」。
- **实时思考字幕卡**（`ThinkingCaption`，`ui/floating_ball.py:154`）：球上方一张**液态玻璃**小卡，半透白渐变 + 顶部品牌色淡染 + 卡内微光扫掠，承载流动中的思考片段。文字 `TextWordWrap` 自适应、自动淡入淡出，不与主聊天窗的思考块重复，而是「球形态下的轻量预览」。
- **调性统一**：字幕卡配色直接取 `brand()["main"]`（`ui/theme.py`），随主题（翠绿/天蓝/墨夜/深蓝）自动适配，未引入新色板，保持品牌一致。

## 2. 一致性检查

- 思考态原有语言（旋转弧 / 粒子 / 波纹 / 反向细弧）全部保留，本次为**叠加增强**，无视觉冲突。
- 新增 🧪 产物预览按钮与既有标题栏按钮（📚/📦/✨/⚙）同尺寸(30×30)、同 `FlatButton` 样式、同 hover 放大，布局连贯。
- 字幕卡的不参与鼠标事件（`WA_TransparentForMouseEvents`），不抢交互，符合「悬浮球上方提示」的既有设计语言（参考 `TipBubble`）。

## 3. 评分

**A（美术）**：在「更克制地让思考被看见」上做了增量精修，液态玻璃 + 微光与品牌色体系融合自然；信息层级合理（球=状态，卡=思考片段，聊天窗=完整思考块）。
建议（非阻断）：字幕卡在 4K/高分屏下可按 DPR 微调字号；微光扫掠速度可随主题微调以区分「思考 / 输出」节律。
