# 评审纪要 · v11.3.0

> 评审对象：v11.3.0 的**安卓闪退根治**与**电脑端新增功能（消息收藏 / AI 总结 / 批量导出）**。
> 工作流：代码安全性评估 → HR 复审 → 美术复审 → 资深程序员复审 → GitHub 复审 → 反复优化 → 创造力复审 → API 开放文档。

## 1. 代码安全性评估
- 安卓 `_show_fatal_error` 仅拼接本地异常文本到 `toga.Label`，**无 `eval` / 命令执行 / 路径拼接**，无注入面。
- `build_summary_prompt` 为纯函数，仅读取消息内容拼提示词，**不执行、不落盘外部输入**；模型返回文本经 `set_summary` 存入 `session["summary"]`，下游仅渲染，无代码执行风险。
- `export_all_sessions(fmt="zip")` 使用 `zipfile` 内存打包，文件名由会话 `id[:8]` 生成（非用户可控串），**无 Zip Slip / 路径穿越**（不读取外部路径，仅写内存缓冲）。
- 签名密钥 `starry-release.keystore` 留在仓库 `android/` 下用于 CI/本地演示；生产建议移出仓库、走 CI Secret。已在 `.gitignore` 关注 `*.key` 类文件，后续可补一条 `android/*.keystore` 忽略规则（当前为演示便利保留）。

## 2. HR 复审（用户价值 / 上手）
- 「收藏最后回复」「收藏夹」「AI 总结」「批量导出」四个入口**全部进命令面板（Ctrl+K）**，延续「一键可达」心智，老用户零学习成本。
- 安卓闪退从「安装即闪退」变为「屏上显示原因 + logcat」，用户不再面对黑盒崩溃，自助排查与反馈效率显著提升。

## 3. 美术复审（视觉一致性）
- 收藏夹对话框沿用会话管理框的 `QListWidget` 卡片样式（`#fafbfc` 底、`1px #e3e8ef` 边、选中 `#e6f2ff`），视觉语言一致。
- 命令面板图标沿用 emoji 体系（⭐📌📋📦），与既有 📝 导出同组，不破坏面板排版。

## 4. 资深程序员复审（架构 / 可维护性）
- 新增能力**零 Qt / 零安卓依赖**，全部落在纯逻辑 `core/sessions.py` 与 `core/exporter.py`，桌面与安卓共用同一份，符合「一处代码多端分发」。
- `toggle_star` / `list_starred` / `set_summary` / `get_summary` 与既有 `set_pinned` / `edit_message` 风格一致（越界返回 `None`/`False`，持久化收敛到 `self.save()`）。
- `build_summary_prompt` 作为模块级纯函数，已单测覆盖「过滤系统提示」「空对话兜底」。
- 安卓 `_do_turn` 用「内层 try 细分 + 外层 try/finally 复位」结构，确保任意异常都 `finally: _reset_send()`，避免后台线程抛错后 `busy` 永久为 True 的卡死。

## 5. GitHub 复审（工程 / 发版）
- `.github/workflows/build-android.yml` 沿用：推送 `v11.3.0` tag 即在运行器**真实编译并签名 APK、自动发布 Releases**。本轮额外验证：本地「干净重建 + `gradle assembleRelease` + `zipalign` + `apksigner`」链路可稳定产出可安装签名 APK。
- 版本号 11.2.0 → 11.3.0 在桌面/安卓 `config.py`/`mcp.py`/`pyproject.toml`/selftest 四处同步，杜绝「界面写新、配置写旧」的漂移。

## 6. 创造力复审
- 「批量导出全部会话为 ZIP（含 index.md）」对齐 ChatGPT/Claude 的「导出全部历史」体验；「AI 总结 + 缓存」对齐笔记类产品的「会话摘要」能力，但实现为纯本地、无额外云依赖。
- 安卓「错误窗口而非闪退」是把「崩溃」转化为「可观测错误」的产品化思路，提升移动端健壮性。

## 7. 反复优化结论
- 安卓构建原依赖联网下载 JDK17，沙箱超时失败；改为复用系统已装 JDK17，链路稳定。该经验已写入 `android/README.md` 的构建说明。
- 历史大版本（v7.6 / v8.0 / v9.0 / v10.0 / v11.0 / v11.1 / v11.2）均保留，未覆盖。
