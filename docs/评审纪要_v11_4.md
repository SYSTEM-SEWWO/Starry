# 评审纪要 · v11.4.0

> 评审对象：v11.4.0 的**电脑端新增功能（消息引用 Quote / 分支对话 Branch）**及全链路升级。
> 工作流：代码安全性评估 → HR 复审 → 美术复审 → 资深程序员复审 → GitHub 复审 → 反复优化 → 创造力复审 → API 开放文档。
> 分项详版见 `代码安全性评估_v11_4.md` 等 6 份文档，本纪要为汇总。

## 1. 代码安全性评估
- `format_quote` / `build_quoted_prompt` 为**纯函数**：仅读取消息内容、拼装字符串，不执行、不落盘外部输入，无 `eval` / 命令执行 / 路径拼接，无注入面。
- 引用块把历史消息**原文**注入新 user 消息发给模型，属常规 prompt 组合；未引入文件系统 / 网络 / 子进程调用。截断（`QUOTE_MAX_CHARS=300`）同时限制了上下文膨胀。
- `branch_from` 仅对内存中的 `messages` 做浅拷贝与切片，写入本地 `sessions.json`（沿用既有原子写入 `core.storage.save_json`）；`branched_from` 只存 `session_id` + `index` 整数，无用户可控路径，无 Zip Slip / 路径穿越。
- 消息选择器 `MessagePickerDialog` 展示文本用 `setToolTip` / `QListWidgetItem`，为富文本控件安全 API，不做 HTML 拼接执行。

## 2. HR 复审（用户价值 / 上手）
- 「引用消息追问」「引用最后回复」「分支对话」「分支列表」四个入口**全部进命令面板（Ctrl+K）**，延续「一键可达」心智，老用户零学习成本。
- 引用解决「针对上文某句追问」的高频诉求；分支解决「想换方向重试但不想覆盖原对话」的诉求，都是对话类产品的核心体验补齐，用户价值正向。
- 旧 `sessions.json` **无需迁移**：新增字段全部 `.get()` 读取，历史数据零损升级。

## 3. 美术复审（视觉一致性）
- `MessagePickerDialog` 完全沿用收藏夹 / 会话管理框的 `QListWidget` 卡片样式（`#fafbfc` 底、`1px #e3e8ef` 边、选中 `#e6f2ff`、hover `#f0f6ff`），视觉语言统一。
- 引用/分支**两种模式共用一个对话框**，通过标题、提示文案、是否显示追问输入框区分，避免新增两套界面造成风格漂移。
- 命令面板图标沿用 emoji 体系（💬↩️🌿🌱），归入「对话」组，与 ⭐📌📋 收藏/总结同组，不破坏面板排版。

## 4. 资深程序员复审（架构 / 可维护性）
- 新增能力**零 Qt / 零安卓依赖**，全部落在纯逻辑 `core/sessions.py`，`core/sessions.py` 与 `android/core/sessions.py` 保持**字节一致**，符合「一处代码多端分发」。
- 两个纯函数（`format_quote` / `build_quoted_prompt`）刻意做成无副作用，便于单测与跨端复用；`SessionStore` 便捷方法 `quote_block` 委托纯函数，避免逻辑重复。
- `branch_from` 对每条消息**浅拷贝**，改动分支消息不污染原会话（单测已验证）；`starred` 按下标 `<= index` 过滤，避免引用到被截断消息；`branched_from` 溯源 + `list_branches` 聚合，结构清晰。
- **AST 校验**：插入新方法后类方法数 33，`delete/append/messages/set_messages` 仍在类内、模块级纯函数独立——规避了上一版「函数误插导致方法游离出类」的坑。
- **索引一致性**：打开选择器前 `_save_current_session()`，确保 UI 的 `history` 与 `sessions.messages` 下标一致（启动时可能补 `system` 提示但未写回，会造成偏移）——这是本轮识别并预防的隐性 bug。

## 5. GitHub 复审（工程 / 发版）
- 版本号 11.3.0 → 11.4.0 在桌面/安卓 `config.py`/`mcp.py`/`pyproject.toml`（2 处）/selftest（4 处断言）**四处同步**，杜绝「界面写新、配置写旧」漂移；CLI `--version` 实跑打印 11.4.0。
- `.github/workflows/build-android.yml` 沿用：推送 `v11.4.0` tag 即在运行器真实编译并签名 APK、自动发布 Releases。
- 沿用 v11.3 已验证的**干净重建**链路（JDK17 + gradle wrapper 9.5.0 + assembleRelease + zipalign + apksigner），APK 内部版本同步核验为 11.4.0。
- 5 个带后缀版本文件夹 + zip 分发，每个含完整工程（源码 + 全部 docs/md + 主文件 + README/CHANGELOG）。

## 6. 创造力复审
- 「从任意历史消息分支出新会话」对齐 ChatGPT / Claude 网页端的「从此处新建分支」与 Git 的 branch 心智，把版本控制思想引入对话管理，`branched_from` 溯源 + 分支列表可视。
- 「引用 + 追问组合提示」把碎片化的 "@ 某条消息" 交互，抽象为**可单测的纯函数**（引用块格式化 + 上下文指令拼装），既服务桌面 UI，也可被安卓 / 未来插件复用。
- 消息选择器「一框两用」（引用 / 分支）是复用式设计，减少 UI 表面积。

## 7. 反复优化结论
- 识别并预防了**启动补 system 提示造成的下标偏移**：所有引用/分支操作前先落库对齐索引，避免"选了第 2 条却引用到第 3 条"的错位。
- 引用块对 `system` / 空内容 / 多模态 / 超长 / 多行逐一兜底，9 项单测覆盖边界；V11.3 回归 4/4 无破坏。
- 历史大版本（v7.6 / v8.0 / v9.0 / v10.0 / v11.0 / v11.1 / v11.2 / v11.3）全部保留，未覆盖。

**总结**：v11.4.0 无新增安全风险，架构延续「core 纯逻辑同源 + 桌面 UI 薄接入」，用户价值与可维护性正向，建议发版。
