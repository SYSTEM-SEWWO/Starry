## 2. 多线并行：本版任务波次

```
波 0  整体项目（能力矩阵 / 验收口径）
       │
       ├── 线 A：core/hub.py + skills/ 示例 ──────┐
       ├── 线 B：CLI / 桌面接入 ─────────────────┤
       ├── 线 C：GUI EXE spec + 自检入口 ────────┼→ 波 1：接入门禁测试 119 项
       └── 线 D：CI / deb / 版本真源 ────────────┘        │
                                                           ↓
                                        波 2：全量回归 1186 项 → 产物重建 → 子进程冒烟
                                                           ↓
                                        波 3：六类复审 + 创造力评价 + 文档矩阵 + 快照
```

单线失败不影响其它线：例如 CLI EXE 冒烟先出现编码判定失败，
只回头修 `starry_cli.py` 与冒烟脚本，GUI EXE 与全量回归结果不受影响。

## 3. 真实缺陷闭环（不是「应该没问题」）

| # | 现象 | 根因 | 修复 | 证据 |
| --- | --- | --- | --- | --- |
| 1 | `allowed-tools: Read, Bash, Grep` 解析成字符串 | `_scalar()` 未识别内联列表语义 | `_LIST_KEYS` + `_as_list()` 在 frontmatter 出口归一化 | 单测 3 项 |
| 2 | `metadata.version` 读不到 | 嵌套映射未消费 | `parse_skill_md` 回退读 `metadata.version` | 单测 1 项 |
| 3 | 往返比对时每个技能同时 added + removed | `parse_hub_entry` 用 `remote:` 重造 id | 已有 id 原样沿用，用条目 `source` 拼装 | 单测 2 项 |
| 4 | 每个技能都被判 changed | 用空正文**重算**的 sha256 比对 | 改用清单**声明**的 sha256 | 单测 1 项（往返无更新） |
| 5 | 扁平技能名被文件名覆盖 | `name` 参数优先级高于 frontmatter | 改为 `meta.name → name → 目录名` | 单测 1 项 |
| 6 | `_as_list(dict)` 产生垃圾 | `str(dict).split(",")` | dict 返回 `[]` | 单测 1 项 |
| 7 | 缺文件用例「假绿」 | 参数未接入时 argparse 也返回 2 | 接入后核实真实报错 + `cli_run` 收敛 SystemExit | 手动复跑 RC=2 |
| 8 | spec 接入断言过松 | `"hub" in spec.lower()` | 精确到 4 个模块 + datas + workflow | 单测 6 项 |
| 9 | CLI EXE 中文冒烟 6/14 | 管道下输出为 cp936，脚本按 UTF-8 解码 | EXE 尊重 `PYTHONIOENCODING`；脚本多编码候选解码 | 冒烟 14/14 |
| 10 | v13.0 遗留 P0-2 测试与发版号耦合 | 硬编码 `APP_VERSION == "13.0.0"` | 改 SemVer 下限 + release.yml 动态注入 | v13 单测 172/172 |
| 11 | v13.0 快照内 `RELEASE_NOTES.md` **只有一行占位**（已核实文件） | 脚本拼 `RELEASE_NOTES_v13_0_0.md`，项目实际叫 `RELEASE_NOTES_v13_0.md`；名字不匹配时静默退化成占位，而 `release.yml` 用它当 Release 正文 | 三级回退：三位版本 → 两位版本 → 根目录 `RELEASE_NOTES.md`；补单测锁死 | 快照终验检查正文长度与结构 |
| 12 | 快照目录白名单漏 `skills/` | 旧白名单只有 core/ui/app/android/assets/scripts/tests/docs/tools/.github | 补入 `skills`；补单测断言 | 快照内 `skills/` 文件数 |

## 6. 已知限制（不得写成「已完成」）

1. 本机无 JDK 17 / Android SDK / NDK / Gradle / apksigner，**不产出 v13.1 签名 APK**；
   `releases/assets/v13.1.0/apk/` 只放 README。真机 / 模拟器未跑，不能声称实测不闪退。
2. 当前目录**不是 git 仓库**，workflow 已备好但需用户 `git init` + 首次提交 + remote + tag 才触发。
3. `releases/星语Starry-v11.5.0/` 含历史 `starry-release.keystore`，公开分发前必须轮换。
4. `hub.json` / `update.json` 的 digest 是完整性校验，不是签名认证。
5. GUI 自检是 offscreen 装配验证，**未做真人交互点击测试**。
6. frontmatter 解析器是有意限定的 YAML 子集，不支持锚点 / 复杂嵌套。
