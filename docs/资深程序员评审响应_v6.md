## 二、顺带修掉的两个自测问题（程序员自查）

1. **fixture 多分片断言偶发失败**：fixture 页 10 字/40ms 的填充速度与 harness 0.25s 轮询存在竞态，短回答可能在一轮轮询内完成。已将 fixture 填充降速为 4 字/80ms，保证多分片场景确定性可测。
2. **网页版卡片文案断言写反**：原断言 `"Key" not in web_sub` 与修复后的合法文案「免 API Key」自相矛盾，改为断言不含「0 个 Key」（HR 反对的是「计数拆台」语义，不是「Key」这个词）。
