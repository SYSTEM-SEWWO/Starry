## 二、轻量化的可核对数据（含一个反直觉结论）

### 1. 代码增量（新功能很小）

| 模块 | 行数 | 职责 |
| --- | --- | --- |
| `core/quickask.py` | 104 | 6 个动作 + 文本清洗 + 提示词合成（纯函数） |
| `ui/quick_ask.py` | 175 | 迷你窗 UI（含隐私说明） |
| `core/idle_tips.py` | 90 | 提示语库 + 时段选择（纯函数） |
| `core/storage.py` | 41 | 原子读写（替代 4 处重复实现） |
| **合计** | **410** | 2 个新功能 + 1 次去重重构 |

运行时总代码 **17,018 行**（v7.1 约 16,300 行）——两个功能只加了不到 3%。

### 2. 存储层去重（维护点 4 → 1）

- 会话 / 统计 / 资料库 / 自动化 4 个类原本各有一份**逐字相同**的 `save()`（各 10 行）；
- 现在统一为 `core/storage.save_json()`，4 处各剩 2 行调用。
- 诚实说明：**总行数没有减少**（40 行 → 41 + 8 行），减少的是「同一逻辑的 4 份拷贝」——
  以后改原子写入语义只改一处，不会再出现「改了三处漏一处」的事故。

### 3. 产物体积（反直觉但必须说清）

| 场景 | 体积 | 说明 |
| --- | --- | --- |
| Linux 单文件（排除 15 个未用 Qt 模块） | **134 MB** | 实测 |
| Linux 单文件（不排除，对照） | **134 MB** | 实测，**差值为 0** |
| UPX 压缩后（Linux） | 134 MB | UPX 4.2.2 对 ELF 不生效（PyInstaller 仅对 Windows PE 使用 UPX） |

**结论：`excludes` 不省体积**。原因很简单——PyInstaller 只收集被导入的模块，
`QtWebEngine/Qml/Quick/3D` 我们从未导入，本来就不在包里；那 15 条排除只是
「防止未来误引入」的保险，不是瘦身手段。把这点写出来，比继续声称「已瘦身」诚实。

**真正的体积构成**：Qt5 的 Core/Gui/Widgets + xcb 平台插件 + 字体/图标，约 130MB 封顶。
对标：Cherry Studio / AnythingLLM 安装包 200MB+，本产品 134MB 单文件（免安装、免运行时）
在同类里仍属「轻」；Windows 上 UPX 生效后预期 60–100MB（**未真机验证，仅预期**）。

若要进一步减重，只有两条真路：① 换 Qt 绑定（PySide6 体积相近）、② 裁掉 Qt 的 translations
与未用 imageformats 插件（约省 10–20MB，收益有限）。本轮不做，已列入 v8 候选。

### 4. 自测成本

selftest 3,175 行 / **601 项**（v7.1 558 → +43）。测试代码量约为运行时代码的 19%——
在桌面 GUI 项目里属于偏高但合理的投入（每个新功能都有可重复验证的路径）。
