## 4. 资深视角的坦白清单（仍需正视）

1. **Windows `.exe` 未在真机运行**：沙箱为 Linux，仅能验证「spec 正确性」；`.exe` 的真实启动 / 托盘 / 高 DPI 表现需在 Windows 上由 `build_windows.ps1` 实跑确认（已在文档标注）。
2. **许可仍为客户端离线校验**：`generate_license_key()` 确定性，逆向可重算——属「防小白不防专家」，正式商用需服务端激活（v7.7）。
3. **无 SCA / 签名**：CI 未做 `pip-audit` 依赖审计；产物未签名（GitHub 复审已建议）。
4. **单仓库单人提交**：缺 PR review 历史，不利展示协作流程。
