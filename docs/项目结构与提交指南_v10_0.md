
## 2. 版本化发布包规范（用户要求）

**规则**：每更新一个版本，把所有更新的内容放到一个文件夹，**后缀带版本号**，
确保每个文件夹打包出来都是**完整的全部项目**（源码 + 全部 `docs/*.md` + 主文件 + README/CHANGELOG），自包含、可独立构建。

V10.0 发布包：

| 文件夹 | 后缀 | 内容 |
| --- | --- | --- |
| `星语Starry-v10.0` | （桌面 GUI 全量） | 完整工程 |
| `星语Starry-v10.0-windows-cli` | windows-cli | 完整工程 |
| `星语Starry-v10.0-linux-cli` | linux-cli | 完整工程 |
| `星语Starry-v10.0-uos` | uos | 完整工程 |
| `星语Starry-v10.0-android` | android | 完整工程 |

> 每个文件夹内容一致（完整工程），后缀仅标识「目标打包平台」，满足「清晰、自包含」。

## 3. 提交指南

- 提交信息遵循 Conventional Commits：`feat: v10.0.0 —— ...`。
- 不入库：`.gitignore` 已忽略 `config.json` / `memory.json` / `.env` / `*.key` 等敏感与运行时文件。
- 文档随代码同提交（评审文档是「证据式」资产，需与代码版本对齐）。

## 4. 打包 / 分发步骤

```bash
# 桌面 GUI 版
bash scripts/build_linux.sh        # → dist/星语Starry-Linux/
powershell -File scripts/build_windows.ps1   # → dist/星语Starry-Windows/星语Starry.exe

# 命令行版（V10.0）
bash scripts/build_linux_cli.sh    # → dist/星语Starry-CLI/
powershell -File scripts/build_windows_cli.ps1
bash scripts/build_uos.sh 10.0.0   # → dist/星语Starry-CLI-UOS.deb
bash scripts/build_android.sh termux   # Termux 指引
bash scripts/build_android.sh apk      # APK 构建命令（需本地 SDK/NDK）

# 版本化文件夹（完整工程）
git archive --format=tar HEAD | (mkdir -p 星语Starry-v10.0 && tar xf - -C 星语Starry-v10.0)
zip -rq 星语Starry-v10.0.zip 星语Starry-v10.0
```
