## 2. 发版文件清单规则

`scripts/make_release.py` 会把以下内容收进版本文件夹：
全部源码、`main.py` / `starry_cli.py`、全部 `docs/*.md`、全部 `.md`、
`skills/`、`scripts/`、`.github/`、`android/`、二进制资产、
`MANIFEST.md`、`checksums.txt`、`SHA256SUMS-v13.1.0.txt`、`RELEASES.md`。

排除：密钥 / 证书 / `__pycache__` / 构建临时目录，
经 `is_sensitive()` 与 `assert_no_secrets()` 双重检查。
重跑同一版本用非破坏性覆盖；`--fresh` 会把旧快照重命名为
`*.prev-<时间戳>` 而不是删除。

## 3. 首次提交到 GitHub

```bash
git init
git add .
git commit -m "feat: 星语 Starry v13.1.0 Skills Hub / GUI EXE / 技能更新"
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main
git tag -a v13.1.0 -m "v13.1.0 Skills Hub / GUI EXE"
git push origin v13.1.0
```

> ⚠️ 推送前处理 `releases/星语Starry-v11.5.0/` 里的 `starry-release.keystore`
> （历史遗留签名私钥），公开仓库必须移除或轮换。

## 4. 本地发版（不依赖 GitHub 也能生成完整快照）

```bash
python scripts/sync_core.py
python scripts/check_core_parity.py --expect-version 13.1.0

python -m PyInstaller starry_cli.spec --noconfirm --clean
python -m PyInstaller starrystar.spec --noconfirm --clean
python scripts/build_deb.py
python scripts/smoke_cli_exe.py --exe dist/星语Starry-CLI.exe --expect-version 13.1.0
python scripts/smoke_gui_exe.py --exe dist/星语Starry.exe --expect-version 13.1.0

python scripts/gen_update_manifest.py --version 13.1.0 \
    --assets-dir releases/assets/v13.1.0 --online
python scripts/make_release.py --version 13.1.0 \
    --summary "v13.1.0 Skills Hub / GUI EXE / 技能更新"
```

## 5. 推 tag 后 CI 会做什么

| workflow | 动作 |
| --- | --- |
| `release.yml` | 版本门禁 → 6 套全量测试 → 生成完整快照 zip → 发布 Release 正文 |
| `build-windows.yml` | 构建 CLI EXE + **GUI EXE**，各自冒烟 → 追加两份资产到 Release |
| `build-android.yml` | 带 Android 工具链时产出签名 APK → `verify_apk.py --strict` → 追加资产 |
| `update-manifest.yml` | Release 完成后下载全部资产 → 生成权威 `update.json` → `--clobber` 回传 |

## 6. 版本升级检查表

升 `X.Y.Z` 时必须同步：

- [ ] `core/config.py::APP_VERSION`
- [ ] `core/mcp.py::CLIENT_INFO["version"]`
- [ ] `android/pyproject.toml` 两处 `version`
- [ ] `scripts/build_deb.py::VERSION` 与 control 描述
- [ ] `release.yml` / `update-manifest.yml` / `build-windows.yml` 的默认版本与示例
- [ ] `README.md` 首屏 / `CHANGELOG.md` / `RELEASE_NOTES.md`
- [ ] `tests/test_v13_features.py` 的 SemVer 下限断言（已去耦合，通常不用改）
- [ ] `releases/assets/vX.Y.Z/` 与 `SHA256SUMS-vX.Y.Z.txt`
- [ ] `RELEASES.md` 索引（由 `make_release.py` 自动追加）

## 7. 完整快照验收命令

```bash
python scripts/check_core_parity.py --expect-version 13.1.0
python tests/test_v13_1_hub.py
python scripts/smoke_cli_exe.py --exe dist/星语Starry-CLI.exe --expect-version 13.1.0
python scripts/smoke_gui_exe.py --exe dist/星语Starry.exe --expect-version 13.1.0
python scripts/verify_release.py --version 13.1.0
```

`verify_release.py` 检查 zip CRC、zip 与目录文件名集合及逐文件哈希、
SHA256SUMS 每条、敏感文件、索引、以及 **`RELEASE_NOTES.md` 不是占位文本**。
CI 中加 `--skip-history`（全新 checkout 可能还没有历史快照目录）。
