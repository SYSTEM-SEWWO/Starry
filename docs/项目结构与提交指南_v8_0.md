## 3. 打包成 exe（三平台，同 v7.6）

```bash
powershell -File scripts/build_windows.ps1   # → 星语Starry.exe
bash scripts/build_linux.sh                  # → 星语Starry
bash scripts/build_macos.sh                  # → .app
```

- `hiddenimports` 已含 `core.memory` / `core.reasoning` / `ui.memory_dialog`（`starrystar.spec`），避免 PyInstaller 静态分析遗漏懒加载模块。
- 浏览器内核与本地模型二进制刻意不内嵌，由产品内按需安装。

## 4. 版本化文件夹约定（用户新要求）

> **需求**：每更新一个版本，把所有更新内容放进一个**带版本后缀的独立文件夹**，确保每个文件夹打包出来都是**完整的全部项目文档 + 全部 md + 主文件**，看起来清晰。

约定（自 V8.0 起执行）：

| 规则 | 说明 |
| --- | --- |
| 文件夹命名 | `星语Starry-v<版本>/`，例如 `星语Starry-v8.0/`、`星语Starry-v7.6/` |
| 内容 | 复制**完整仓库**：全部源码（`main.py` / `app/` / `core/` / `ui/`）、全部 `docs/*.md`、README / CHANGELOG / LICENSE、图标、脚本、打包 spec |
| 自包含 | 文件夹内即可独立构建 / 提交 / 打包，不依赖其他版本目录 |
| 归档 | 每个版本文件夹额外生成同名 `.zip`（如 `星语Starry-v8.0.zip`），便于分发与回溯 |
| 基线补录 | 当前基线 `v7.6` 也补一份 `星语Starry-v7.6/`，使版本演进清晰可见 |

> 见仓库根目录：`/workspace/星语Starry-v7.6/`（基线快照）与 `/workspace/星语Starry-v8.0/`（本版快照）。
